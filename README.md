# ZE8ES

Nowoczesna, responsywna strona internetowa dla studia tworzącego strony, aplikacje i systemy dla firm.

Repozytorium: `totalnybet-create/ZE8EZ`  
Nazwa marki na stronie: **ZE8ES**

## Cel projektu

Zbudowanie od podstaw kompletnej strony firmowej inspirowanej przekazanym projektem graficznym: ciemny interfejs premium, akcenty fioletowo-niebieskie, mocna sekcja otwierająca, prezentacja usług, realizacji, wyników, procesu współpracy i formularza kontaktowego.

## Zasady realizacji

- całość kodu, dokumentacji i historii zmian jest zapisywana w GitHubie,
- małe, opisane commity po kolejnych etapach,
- projektowanie mobile-first i pełna responsywność,
- semantyczny HTML, dostępność WCAG i obsługa klawiatury,
- brak ciężkich zależności w pierwszej wersji,
- optymalizacja Core Web Vitals, SEO i bezpieczeństwa,
- komponenty oraz style nazwane i uporządkowane tak, aby projekt można było łatwo rozwijać.
